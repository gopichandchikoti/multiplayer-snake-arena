# Feature matrix (v1.0.0)

Status: **Done** = implemented and verified as described; **Partial** = implemented with the stated gap;
**Not built** = deliberately not in v1.0.

| Spec feature                                                                  | Status         | Where                                                            | Evidence                                                                                                                                 |
| ----------------------------------------------------------------------------- | -------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Smooth keyboard and touch controls, responsive arena                          | Done           | `game/input.ts`, `game/layout.ts`, `ui/overlays.tsx`             | unit tests; E2E mobile project (swipe via touch events, pad taps, 320 px, portrait rotation)                                             |
| Collision and food pickups                                                    | Done           | `shared/sim/*`                                                   | `sim-collisions.test.ts`, `sim-movement.test.ts`, `sim-effects.test.ts`                                                                  |
| Authoritative fixed-tick server (movement, collision, spawning, scoring, win) | Done           | `server/match.ts` + `shared/sim`                                 | `match-clock.test.ts`, `room.test.ts`, `http-gateway.test.ts`, load test                                                                 |
| Lobby, room codes, nicknames, ready state                                     | Done           | `server/room.ts`, `ui/online/*`                                  | `room.test.ts`; E2E online flow                                                                                                          |
| Matchmaking                                                                   | Partial        | `RoomManager.quickplayCandidate`                                 | Quick play joins the fullest open public lobby. No skill or latency based matching.                                                      |
| Spectator mode                                                                | Done           | watch by code or invite; late joiners watch until the next lobby | `room.test.ts`; E2E (spectator sees the match, "Watching" badge)                                                                         |
| Client interpolation, prediction, reconciliation, lag indicators              | Done           | `net/onlineGame.ts`, `net/clockSync.ts`, `ui/Hud.tsx`            | `online-game.test.ts`; real-network latency tests; HUD badge (bars + words)                                                              |
| Reconnect grace period, disconnect cleanup, deterministic room lifecycle      | Done           | `server/hub.ts`, `room.ts`, `net/gameSocket.ts`                  | `room.test.ts`, latency tests (cut and resume), `net-socket.test.ts`. See KNOWN_LIMITATIONS: the seat is kept, the snake keeps coasting. |
| Round timers, scoreboards, match summary                                      | Done           | HUD, `SummaryScreen`                                             | E2E; unit tests                                                                                                                          |
| Leaderboard                                                                   | Partial        | `server/leaderboard.ts`, `LeaderboardPanel`                      | Per-server only (memory or JSON file); labelled "not a global ranking". No PostgreSQL.                                                   |
| Optional guest profiles                                                       | Done           | random guest ID, nickname, local records                         | `profile.test.ts`, settings tests; no account anywhere                                                                                   |
| Bots for local practice, separate from rankings                               | Done           | `shared/bot.ts`, `game/practice.ts`                              | `prediction-bot.test.ts`, `game-logic.test.ts`; practice is badged "Offline practice, not ranked" and never contacts the server          |
| Anti-cheat input validation, rate limiting                                    | Done           | `protocol.ts`, `session.ts`, `gateway.ts`                        | see THREAT_MODEL.md                                                                                                                      |
| Abuse-safe chat (or none)                                                     | Done (no chat) | n/a                                                              | v1 has no chat; nicknames are sanitised                                                                                                  |
| Original arena themes                                                         | Done           | Parchment, Kiln, Tidepool (`game/palette.ts`)                    | contrast asserted in tests; screenshots                                                                                                  |
| Power-ups with balancing and clear feedback                                   | Done           | Surge, Aegis, Trim; shape, colour and countdown ring             | `docs/GAME_RULES.md`; `sim-effects.test.ts`, `sim-movement.test.ts`                                                                      |
| Colour-independent cues, reduced motion, dark/light                           | Done           | patterns, `Motion` and `Colour scheme` settings                  | axe scans in both schemes; reduced-motion E2E                                                                                            |
| Redis                                                                         | Not built      | optional in the spec                                             | single process by design (ADR 0001)                                                                                                      |
| PostgreSQL                                                                    | Not built      | optional in the spec                                             |                                                                                                                                          |
| Installable/offline PWA                                                       | Not built      |                                                                  | practice needs the page to be loaded once                                                                                                |
| Replays, accounts, skill matchmaking, localisation                            | Not built      |                                                                  |                                                                                                                                          |
